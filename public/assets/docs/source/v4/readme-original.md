# Assets · Bitácora Amorcito · v4

El cabello del personaje, el retrato de XP y las doce poses fue corregido con tonos RGB exactos: base `#795042` e iluminaciones `#c68864`. Las sombras principales usan `#573a31`; se conservan los contornos oscuros y algunos píxeles de borde para mantener la forma pixel art. `assets.json` registra las cantidades verificadas de píxeles para cada color.

El side labret pequeño del lado derecho y la areta negra permanecen en el personaje. Jerry, la ropa y la transparencia se conservaron. El mapa, el letrero y los cinco objetos son los del paquete anterior.

`poses_movimiento_con_jerry.png` es una referencia visual de doce poses, no un atlas de celdas exactas. Para mover el personaje como una sola entidad usa `personaje_movible_con_jerry.png`.

`mapa_paisaje.png` mide 1672 × 941. Las coordenadas iniciales de estaciones constan en `assets.json`.
